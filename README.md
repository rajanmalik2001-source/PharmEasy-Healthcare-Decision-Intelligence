# PharmEasy Healthcare Decision Intelligence

Offline, reproducible Healthcare Decision Intelligence capstone implemented in Python and NumPy.

## Environment

- Python 3.10+
- NumPy 2.3.5 (pinned in requirements.txt)
- No API keys, paid services, or external dataset downloads

Install and run from the repository root:

```bash
python -m pip install -r requirements.txt
python generate_data.py
python part1.py
python part2.py
python part3.py
python part4.py
```

The scripts write all result text and CSV files into `outputs/`. `common.py` contains shared data-loading, splitting, standardization, logistic-regression, KNN, and metric helpers.

## Reproducibility check

The uploaded generator was run successfully against the supplied dataset. It produced 800 records, 10 columns, 170 positive outcomes, and MD5 `e26b46e82f1a1af44dcabc133050802e`. This matched the uploaded `records.csv` byte-for-byte.

All eight supplied reference CSVs (Part 2 thresholds and KNN CV; Part 3 segments and hierarchical clustering; Part 4 splits, voting, AdaBoost, and architecture) matched the files regenerated by the Python scripts byte-for-byte.

## Results summary

### Part 1 — Statistical analysis and regression

- Records: 800; mean care-plan cost: 8.9382 thousand INR; sample SD: 9.1723 thousand INR; standard error: 0.3243.
- 95% confidence interval for the mean: 8.3026 to 9.5738 thousand INR.
- Test against mean 8.0: z = 2.8930; reject the null at the 5% level.
- Required sample size for 0.5 precision: 1,293.
- Simple regression: slope 0.6701, intercept -3.6598, R² 0.5196, RMSE 6.3537, MAE 3.7636.
- Gradient descent slope gap from the closed-form slope: 0.0000.
- Log-log regression: slope 1.5030, R² 0.6565.
- Multiple regression adjusted R²: 0.7403.

Full computed keys are in `outputs/part1_results.txt`.

### Part 2 — Logistic regression, thresholds, and KNN

- Stratified split: 560 training rows (119 positives), 240 test rows (51 positives).
- Logistic test BCE: 0.3818.
- At threshold 0.5: TP 24, FP 20, TN 169, FN 27; F1 0.5053.
- At threshold 0.3: TP 38, FP 44, TN 145, FN 13; F1 0.5714.
- Best KNN K from the prescribed five-fold CV: 5; test F1: 0.3696.
- Cost-minimizing training threshold: 0.15; test cost at this threshold: INR 6,050, versus INR 11,800 at threshold 0.5.

See `outputs/part2_results.txt`, `outputs/part2_thresholds.csv`, and `outputs/part2_knn_cv.csv`.

### Part 3 — Segmentation, hierarchical clustering, and PCA

See `outputs/part3_results.txt`, `outputs/part3_segments.csv`, and `outputs/part3_hierarchical.csv`.
